# Thot Assistant — pages publiques

Ce dépôt ne contient **que les pages publiques** de l'application
[Thot Assistant](https://play.google.com/) : un carnet de bord pour
enseignants, gratuit et sans publicité.

| Page | Adresse |
|---|---|
| Politique de confidentialité | https://thot-boomerang.github.io/ |

Le code de l'application est développé dans un dépôt séparé.

## Pourquoi cette page existe

Google Play exige une politique de confidentialité accessible
publiquement, à une adresse stable, pour toute application publiée.

## L'essentiel de cette politique

Thot Assistant fonctionne **entièrement sur l'appareil**. Aucune donnée
n'est collectée, aucune n'est transmise. Pas de compte, pas de publicité,
pas de traceur, pas de mesure d'audience. L'éditeur n'a accès à rien de
ce que l'utilisateur saisit, y compris les informations concernant des
élèves.
